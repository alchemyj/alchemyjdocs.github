    ajLogWarn function

    Available since AlchemyJ v5.1

    Description

    The ajLogWarn function allows user to output custom-formatted log message to the system log file according to the program-defined WARN level.

    This function allows user to customize the log prefix(format) and dynamically pass in the specific content to be recorded, facilitating subsequent debugging, monitoring, and problem tracking.

    Syntax

    ajLogWarn(format, argument)

    Argument NameArgument TypeDescription
    format
    (required)    		StringCustom log format. Used to define the log prefix or template, only supports {} as the placeholders to receive the following argument parameter. for example: "UserLogin{}".
    argument
    (optional)    		StringThe actual content of the log. This is the specific information you need to record. This content will be filled into the placeholder positions in the format.

    The function will return:

    1) Return Value: 1.

    2) Return Type: Single Value

    Example

    Before using ajLogWarn, the Log Level must be set up to Warn level in the Runtime Configuration in ##RestApi worksheet. Otherwise, this log might not be output.

    Example 1 - Basic Text Record

    The most basic usage is to record a fixed text or status

    ajLogWarn("Test","Warning log message testing")

    Log output when log level is INFO

    ....- Test: Warning log message testing

    Example 2 - Log variables along with their contextual information

    In practical business scenarios, it is often necessary to record the details of a specific action (such as user ID, order number, etc.).

    2026-11-03 18:28:25.845 [http-nio-8080-exec-1] WARN  com.alchemyj.ajLogTest_001 - UserAction:User U10086 executed pay success operation.

    Error Scenarios

    It will return #VALUE! when missing any required parameter or mismatch parameter type.
